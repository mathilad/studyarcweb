HOW STUDY ARC THINKS

An adaptive study plan built from your real study data.

Study Arc does not simply rotate subjects on a fixed timetable. It builds a priority queue from the topics you have covered, your knowledge, memory and performance, weak-topic test results, revision due dates, class timing, available hours and exam phase. It then fits the highest-value work into the time you actually have.

THE FULL LOOP

From student input to tomorrow's plan.

The planner repeats the same cycle every day: collect constraints, decide what matters most, build a balanced plan, record what happened, and feed that new information back into future planning.

01
Build the student context

Subjects, manually covered topics, wake and sleep times, self-study target, classes, protected time, exam settings, topic progress and test marks become the planner's inputs.

02
Filter what is eligible

The planner only queues topics marked as covered. In exam-focused phases it can also restrict scheduling to selected exam subjects and topics, while completed exam subjects can be removed.

03
Score every eligible topic

Knowledge, memory, performance, weak-topic hits, revision due dates and class urgency determine which topics need attention first.

04
Balance subjects

The engine avoids letting one weak topic consume the whole timetable. Weekly targets and already allocated minutes are used to keep subject buckets balanced.

05
Fit sessions into the real day

Classes, travel, pre-class review, protected time, meals, sleep and routine blocks are placed first. Study fills the usable gaps.

06
Learn from the result

Study sessions, test marks and topic progress update the data used by the next plan, creating a continuous feedback loop.

PRIORITY ENGINE

Weakness is measured, then adjusted by urgency.

Study Arc uses a lower-is-more-urgent score. A topic with weaker progress, repeated weak-topic marks, a due revision or an approaching class receives a lower score and moves toward the front of the study queue.

Normal topics: base score = 35% knowledge + 35% memory + 30% performance Biology: base score = 25% knowledge + 50% memory + 25% performance Weak-topic penalty = up to 36 points Revision due penalty = 20 points (28 for Biology) Recent class-topic focus = 30 additional priority points

BALANCE + FAIRNESS

The weakest topic does not get the entire week.

Subject buckets

Study Arc groups work into subject buckets and compares each bucket's target minutes with the time already allocated.

Mathematics balance

Pure Mathematics and Applied Mathematics can be treated as one Mathematics planning bucket for weekly balance.

Weekly target

The planner starts from the student's self-study-hours target and distributes time across active subject buckets.

Manual adjustments

Weekly subject adjustments can increase or reduce how much time a bucket is expected to receive.

Repeat penalty

When the same topic is selected repeatedly, its temporary usage penalty grows so another useful topic can enter the plan.

Covered topics only

The automatic weakness queue uses topics explicitly marked as covered, preventing the planner from assigning untouched content as revision.

REAL-LIFE SCHEDULING

The timetable is built around the day, not on top of it.

Fixed time is protected first

Wake routine, lunch, dinner, wind-down, classes and protected-time blocks are inserted before self-study. Physical classes can also include travel buffers, and classes can add targeted pre-review.

Missed classes

A class marked missed is removed from that week's fixed schedule.

Rescheduled classes

A replacement date and time can be inserted into the plan as a make-up class.

Sleep-aware planning

Changing wake or sleep time changes the available planning window, so future schedules adapt without changing academic priorities.

Study target

The normal target is based on the user's configured self-study hours, constrained by the real available day.

Exam-month intensity

Exam Month increases the academic target significantly and can count class time toward that total.

STUDY PHASES

The algorithm changes as the exam approaches.

The built-in phase suggestion uses the number of days remaining until the exam window. Each phase changes the planner's emphasis rather than replacing the entire scheduling system.

READINESS, NOT GRADE PREDICTION

Study Arc is designed to show preparation, not promise a grade.

A useful study system should tell students what is ready and what still needs work. Readiness can be expressed through signals such as syllabus coverage, paper practice, revision consistency and weak-topic recovery rather than claiming that a student will definitely receive a particular grade.

The goal

Turn study history into a clear next action: what to revise, what to practise, when to do it, and why that task deserves attention now.

FEEDBACK LOOP

Every useful action should improve the next plan.

Study sessions

Completed work adds real study history and progress data instead of relying only on planned time.

Test results

When the student identifies weak topics after a test, those topics receive stronger scheduling priority.

Revision due dates

Topics with a due recall date move upward again, supporting spaced revision.

Class changes

Missed, rescheduled and current class-topic information changes the near-term timetable.

Exam progress

Exam subjects and topics can narrow the queue during high-focus phases.

New plan

The next generated timetable uses the updated state, closing the loop between planning and actual performance.
